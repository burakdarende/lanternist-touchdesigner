Lanternist Studio for TouchDesigner

1. Start Lanternist Studio (this computer or another one on the network).
2. The Studio page says "Connected to ..." within a few seconds. Type Studio's
   address there if it is on another network.
3. Send to Studio: pick a TOP in "TOP 1" (up to four). Spout sends it on this
   computer at full size; NDI sends it over the network. In Studio, open the
   Library's Live inputs: TouchDesigner's senders are listed under TouchDesigner.
   Drop one on a surface.
4. Studio parameters: every parameter of the Studio project, both ways.
5. GO / BACK / Go to cue run Studio's cue list.
6. From Studio: switch on "Receive a Studio output", type the name Studio
   sends under (an output shared over Spout or NDI); this component's output
   connector carries the picture.
